# Jericho Stewardship Group

A lightweight static website for sharing information, updates, and resources from Jericho Stewardship Group.

## Files

- `index.html` contains the page content and navigation.
- `styles.css` contains the responsive layout and visual styles.

Edit `index.html` to update the site's text or add static sections. Edit `styles.css` to change the presentation. No build step or JavaScript is required.

To publish the site with GitHub Pages, select the branch and folder containing `index.html` in the repository's Pages settings.
